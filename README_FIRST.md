# À LIRE EN PREMIER

La démo active se trouve dans :

```text
backend\OPERATION_EVO
```

Sous Windows :

1. Ouvrir ce dossier.
2. Exécuter `setup_windows.bat` une seule fois.
3. Exécuter `run_windows.bat` pour lancer l'application.

Connexions de démonstration :

```text
Administrateur : `admin@operation-evo.local` / `Admin123!`
Utilisateur : `agent@operation-evo.local` / `Agent123!`

L'administrateur est redirigé vers `/admin`. L'utilisateur est redirigé vers son espace personnel `/dashboard`.
```

Le dossier `frontend` contient un ancien prototype Angular et n'est pas nécessaire pour la démo Flask actuelle.

Consulter `backend\OPERATION_EVO\README.md` pour la documentation complète.
